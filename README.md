# HUD Stuff (Fabric 26.3)

Java Fabric port of **HUD Essentials** concepts for Minecraft **26.3**.

## Features (v1.0.0)

- **Overlay HUD** (top-left): XYZ, facing, biome, light level, chunk coords, day time
- **Toggle key** (default: `H`)
- Clean client-only rendering (no server required for basic HUD)

## Planned / from Bedrock original

- Chunk border visualization
- Last-death waypoint
- Custom waypoints
- Inventory warnings
- Crop / light helpers
- Settings screen

## Build

Requires Java 25 + Gradle 9.6+.

```bash
gradle build
```

## Install

1. Fabric Loader 0.19.5+ for 26.3
2. Fabric API 0.165.0+26.3
3. Drop the jar into `mods/`
